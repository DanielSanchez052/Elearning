🌎 Multipaís en cursos
Tabla pivot course_countries (M:N). Un curso puede estar en varios países. Si is_global=true, se ignora la pivot y el curso es visible a todos.
📊 Nivel Móvil
Se calcula en tiempo real: COUNT(completados del país) / COUNT(courses WHERE is_active AND país). El denominador se recalcula con Redis cuando cambia el catálogo.
🏅 Medalla Velocista
Se compara completed_at − started_at (de course_enrollments) con courses.time_limit_mins. Si está bajo el umbral → medalla automática.
❓ Quizzes flexibles
Cualquier lección puede ser de type=quiz en cualquier posición del curso (order_index). El campo is_required controla si bloquea el avance.
🔒 País fijo por usuario
El campo users.country_id no tiene lógica de cambio. Solo el Super Admin podría modificarlo vía SQL/panel especial si fuese necesario.
🔁 Intentos de quiz
Controlado por quiz_questions.max_attempts y user_lesson_progress.attempts_used. Cada intento actualiza el score y el contador.
